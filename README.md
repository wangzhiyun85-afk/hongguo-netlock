## 这是什么

红果短剧的广告是**在线拉取**的：剧集下载/缓存好之后，只要让它连不上网，内容照样播，广告却拉不下来。

这个小工具就是干这一件事 —— **一键切断「红果免费短剧」的网络，需要时再一键恢复**。不 root、不刷机、不装框架，其他 App 的网络完全不受影响。

界面只有一张背景图：联网是一张，断网换成另一张，点屏幕任意位置即可切换。

## 亮点

- **一键切换**：点悬浮球 / 点屏幕 / 点通知栏按钮，三种方式随时断网与恢复
- **只断红果**：只把 `com.phoenix.read` 的流量收进本地隧道后丢弃，微信、视频、游戏照常用
- **没有绕过口子**：IPv4、IPv6、DNS 一并接管，避免「断了网还能弹广告」
- **不申请联网权限**：App 自身不联网、不上传、不统计，纯本地工具
- **常驻悬浮球**：40dp 半透明小圆点，绿圈=联网、红圈=已断网；可拖动、可记忆位置，不属于任何任务，清理最近任务也划不掉
- **自动自愈**：60 秒心跳 + 90 秒看门狗 + 亮屏/切网自检，隧道掉了会自己重建
- **状态永远真实**：通知、界面、悬浮球都以「隧道是否真的在拦截」为准，不会出现「显示已断网其实没断」

## 使用说明

### 1. 安装

下载 APK 安装即可（Android 8.0 及以上）。也可以自己构建，见文末。

### 2. 首次打开，授权三件事

| 授权 | 位置 | 作用 |
| --- | --- | --- |
| **VPN 连接请求** | 首次点断网时系统弹窗 | 断网的核心通道，必须允许 |
| **通知权限**（Android 13+） | 系统弹窗 | 常驻通知与通知栏开关 |
| **显示在其他应用上层** | 界面底部「悬浮球」 | 悬浮球保活（主要使用方式） |

### 3. 日常使用

- **点悬浮球**：联网 ⇄ 断网切换（未授权 VPN 时会自动打开状态页引导）
- **长按悬浮球**：打开状态页
- **拖动悬浮球**：换位置，会自动记住
- **点状态页任意处**：同样是切换
- **通知栏**：`断网红果 / 恢复联网`、`系统联网控制`、`退出常驻`

### 4. 自定义图片

状态页底部点 **「图片」**：

- **更换联网背景 / 更换断网背景**：从相册选一张图，立即生效（自动按屏幕宽度压缩，不吃内存）
- **更换悬浮球头像**：选的图会被裁成圆形，绿圈 / 红圈状态描边照常保留
- **恢复默认图片**：一键回到内置素材

图片只存在 App 私有目录，通过系统文件选择器读取，**不需要存储权限**。
桌面图标目前不支持运行时更换 —— 那需要切换 `activity-alias` 组件，会把当前任务（包括贴边小窗）关掉。

### 5. 建议的保活设置（国内 ROM）

悬浮球已经比普通 App 更抗杀，但想让它 24 小时不掉，再做两件事：

1. **允许自启动**（设置 → 应用 → 红果断网 → 自启动）
2. **电池优化设为「不限制 / 允许后台活动」**（ColorOS：耗电管理 → 允许完全后台行为）

不需要时可在通知栏点「退出常驻」，彻底结束。

### 6. 不想用常驻？还有个更彻底的办法

界面和通知栏都有「系统联网控制」入口，直接跳到系统自带的**按应用断网**页面，把红果的「移动数据 + WLAN」都关掉。一次设置、永久生效，完全不需要本 App 在后台活着 —— 只是不能一键恢复。

## 工作原理

```
红果 App ──流量──▶ 本地 VPN 隧道 ──▶ 丢弃（黑洞）
其他 App ────────▶ 正常网络（不经过隧道）
```

使用 Android 官方 `VpnService`，通过 `addAllowedApplication("com.phoenix.read")` 只接管红果的流量，隧道内读到的数据包全部丢弃。同时添加 IPv4 `0.0.0.0/0` 与 IPv6 `::/0` 路由，并把隧道内 DNS 指向黑洞地址，防止 DNS 泄漏导致广告仍然加载。

保活由前台服务 + 通知栏常驻 + `START_STICKY` + 开机自启 + 定时看门狗 + 悬浮窗组成；断网开关只切换隧道，不重启任何组件，所以贴边小窗、悬浮球都不会被打断。

## 从源码构建

需要 JDK 17 与 Android SDK（compileSdk 34）。

```bash
# 1. 准备本机配置（不入库）
cat > local.properties <<'EOF'
sdk.dir=/path/to/android-sdk
RELEASE_STORE_FILE=../apk/jingxuan.keystore
RELEASE_STORE_PASSWORD=你的密码
RELEASE_KEY_ALIAS=你的别名
RELEASE_KEY_PASSWORD=你的密码
EOF

# 2. 构建
./build.sh          # 产物：apk/jingxuan-netlock-<版本>.apk
```

> 签名文件 `apk/jingxuan.keystore` 与 `local.properties` 都已被 `.gitignore` 忽略。没有自己的签名也可以直接把 `signingConfigs` 去掉，用 debug 签名安装。

## 已知限制

- 同一时间只能有一个 VPN 生效：开着其他 VPN（如代理工具）时，本工具无法工作
- 「杀不死」的保活在国内 ROM 上并不存在，最终取决于系统白名单设置
- 仅面向红果短剧（包名 `com.phoenix.read`），换 App 需改 `BlockService` 里的 `TARGET`
